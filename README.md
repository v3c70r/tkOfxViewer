# tkOfxViewer
![Application screenshot](https://raw.githubusercontent.com/v3c70r/tkOfxViewer/refs/heads/main/screenshots/screenshot.png)
tkOfxViewer is a lightweight Python-based tool designed to visualize the contents of an OFX (Open Financial Exchange) file. It provides a simple and intuitive interface for reviewing financial transaction data.

## Features

- Parses and visualizes data from OFX files.

- Displays a clear overview of transaction items.

- Easy-to-use command-line interface.

## Usage
```
python3 tkOfxViewer.py <ofx_file>
```
